## ◉ 01 — Mission

This repository contains a static website for **Government Jubilee Inter College, Lucknow**. It brings key college information and navigation into one responsive web experience.

## ◉ 02 — Available modules

| Module | Purpose |
|---|---|
| Home | College introduction and highlights |
| About | College information |
| Admission | Admission information |
| Notices | Announcements |
| Our Result | Result information |
| Gallery | Campus photographs |
| Contact | Contact details |
| Quick links | Scholarship portal and UP Board syllabus |

## ◉ 03 — Technology stack

- **HTML5** — page structure and content
- **CSS3** — responsive layout, visual styling and animation
- **JavaScript** — interactive navigation and page behaviour
- **GitHub Pages** — static website hosting

No server-side runtime or paid API is required for the current static site.

## ◉ 05 — Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. For a local development server, run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## ◉ 06 — Deployment protocol

The GitHub Actions workflow in `.github/workflows/deploy.yml` publishes the repository to GitHub Pages when changes are pushed to the `main` branch. It can also be started manually from the **Actions** tab.

Deployment status: [View workflow runs](https://github.com/xsoftwareabdullah1-create/GovtJubileeintercollegelucknow-/actions).
